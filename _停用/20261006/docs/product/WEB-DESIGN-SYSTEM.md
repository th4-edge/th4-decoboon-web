# 装得清 Web V3 设计系统

> 唯一视觉真源：`src/styles/tokens.scss`。本文说明使用规则，不复制变量值。

## 1. 使用规则

- 颜色、字号、圆角、间距、阴影**只能**引用 Token；页面禁止裸值。
- 新增 Token 必须说明用途与替代方案；一次性视觉需求不得新增 Token。
- 品牌色与 App 分端保留（GAP-UI-001），业务状态色调必须与 App 同源。

## 2. 字阶（冻结）

| Token | 用途 |
| --- | --- |
| `$font-hero` / `$font-display` | 登录品牌首屏 / 页面主标题 |
| `$font-h1` / `$font-title` | 区块标题 / 卡片区标题 |
| `$font-card-title` | 卡片标题、关键数值 |
| `$font-body` / `$font-body-sm` | 正文 / 表格与紧凑正文 |
| `$font-caption` | 辅助说明（≥12px） |
| `$font-micro` | 仅角标、头像字母等非阅读文本 |

禁止 9 / 9.5 / 10 / 10.5 / 11.5px。

## 3. 断点（冻结）

只允许 `1440 / 1280 / 1024 / 768` 四档；禁止百分比 + gap 拼栅格。
1440 为设计基准，1024 为窄桌面降级下限，768 以下按需记录 `NOT_TESTED`。

## 4. 状态表达

状态 = 文字 + 颜色 + 位置（必要时图标）。禁止仅用颜色区分。
业务状态色必须来自 `$status-*` 系列；不得临时选色。

## 5. 组件纪律

- 先用 `docs/product/WEB-COMPONENT-SPEC.md` 登记组件，禁止页面自造卡片、状态标签、抽屉、空态、错误态。
- 新增组件必须回答：现有组件为何不满足、复用范围、状态清单。

## 6. 可访问性

- 禁止 `outline: none`；焦点必须可见。
- 键盘可达全部交互；弹层 `Esc` 关闭并归还焦点。
- 对比度达 WCAG AA。
