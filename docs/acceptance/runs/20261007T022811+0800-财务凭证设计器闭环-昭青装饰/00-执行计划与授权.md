# 执行计划与授权

## 范围

- 模式：财务单角色 Web 高级凭证设计器闭环。
- 环境：Web `http://127.0.0.1:8080`，后端 `http://127.0.0.1:8090`，本地 `decoboon` 数据库。
- 身份：Finance 吴濛濛，昭青装饰，Company 数据范围。
- 目标：修复高级设计器保存错误；在真实浏览器中复制、编辑、保存、发布企业凭证模板；核对前端、接口、数据库结果。

## 授权边界

- 允许：本地浏览器操作、本地接口调用、本地开发库只读核对；本地模板持久化测试。
- 禁止：生产写操作、清库、重建企业、修改财务登录凭证、对外发送、正式会计凭证语义扩展。
- 后端当前 `HEAD` 已包含阶段/验收分布式锁改动；全量编译时若目标目录被 IDE 并发占用，不把构建竞争误判为凭证代码缺陷。

## 完成判定

- 高级设计器加载无递归更新。
- 点击保存必须发出 `document/template/save`，返回 `success=true`。
- 企业模板落库并形成不可变版本。
- 发布接口成功后，发布版本号推进。
- 控制台无 error/warning。
