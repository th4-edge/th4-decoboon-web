## 二、新发现 XA-20261011-020 ｜ P1 ｜ 企业负责人进入「待我量房」被 403（BR-028 违反）

- 复现：企业负责人（张伟）登录 → 左侧「待我量房」→ 页面显示「待量房任务暂不可确认 / 当前账号无权执行该操作」。
- 根因：`statistic/designer/measure/list` 使用 `tenantContext.requireRole(employee, EmployeeRole.Designer)`（精确角色，不含 BOSS 超集），而同域设计队列改用 `requireEmployee`；`TenantContext.requireInternalRole` 的 javadoc 明确「依据 DEC-032 / BR-028，BOSS 是本企业全部内部岗位能力的超集，该方法用于企业内部能力入口」。
- 同类点（同一模式，共 3 处）：`statistic/workbench/designer/queue/list`、`statistic/workbench/designer/report`、`statistic/designer/measure/list`。
- 影响：BOSS 的「待我量房」「设计师工作台」等入口在 Web 上打不开；与 XA-013 同类（工作台入口 vs 后端门禁不一致）。
- 证据：`raw/screenshots/fix-011-measure-context-1440x900.png` + 页面文案 + 源码定位。
- 处置建议：按 `BR-028` 将上述 3 处改为 `requireInternalRole(...)`（属权限变更，需用户/业务确认后执行，并全量回归）。
