# 口径复核：XA-015（阶段计划）与 XA-017（客户接受报价）（2026-10-11 06:50–07:10）

## 一、XA-015 阶段计划生成 —— 复核结论：**非缺陷（按既有裁决口径正确）**

现象：少分项报价生成的项目出现大量「本项不涉及」阶段（本次项目仅「木作吊顶」适用），且适用阶段吃掉整个工期窗口（拆除改造 2026-10-31 → 2027-01-14）。

复核依据：

| 判据 | 内容 | 与实现的关系 |
| --- | --- | --- |
| `DEC-057` NA-01/NA-03 | 空阶段分「本项不涉及」与「应有任务但缺失」；非本项不涉及阶段必须 ≥1 个合同施工任务才能开工，否则只能先核对报价/合同施工行 | 无合同施工行的阶段既不能开工、也不该进入验收，系统先行判定为 `NotApplicable` 与该条一致 |
| `DEC-057` NA-05 | 本项不涉及从项目进度分母与阶段权重剔除 | 适用阶段按权重吸收全部窗口 → 仅 1 个适用阶段时占满窗口，属口径结果 |
| `DEC-048` CONTRACT-TERM-04/05 | 阶段按 `defaultDays` 相对权重与模板标准总工期分摊 | 权重口径一致 |
| `GAP-039` 实施记录 | 系统自动判定 + PM 可复核撤销 | 与代码注释、Web 撤销入口一致 |

**结论**：XA-015 由 P2 缺陷降级为 **非缺陷**；现象根因是**该报价的合同施工行只落在「拆除改造」一个阶段**（数据事实），不是状态机或排期算法错误。

改进建议（P3，非缺陷）：① 项目阶段区标注「本项不涉及由系统按合同施工行判定，项目经理可复核撤销」；② 报价/合同确认时提示「该方案将导致 N 个阶段本项不涉及」，让签约人预期一致。
