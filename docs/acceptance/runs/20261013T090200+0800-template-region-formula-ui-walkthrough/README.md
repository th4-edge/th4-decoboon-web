# 方案模版（Web）区域骨架与公式变量改版 · 页面级走查（2026-10-13）

## 触发

用户对 Web「方案模版」页面的三点反馈：

1. 交互界面丑、没有排版与 UI 设计，输入框 / 表单 / 按钮没有图标，**模版表单**尤其突出；
2. 区域骨架表单里直接暴露了内部决策号文案
   「参考实测值只用于模版内公式校验与实例化打底……（DEC-064 / DEC-062）」；
3. **改版新增的面积与周长是公式最常用的两个变量，但公式里看不到支持、区域里没有给这两个变量命名、也没有变量描述。**

## 结论

三点反馈全部在本地 dev 复现成立，已按「面积 A / 周长 P 一等公民」改版并页面级复验通过。
