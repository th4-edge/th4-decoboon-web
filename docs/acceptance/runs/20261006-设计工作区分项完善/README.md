## 二·补3 · 新增设计项不再整页刷新（用户反馈修复）

**问题**：每次新增/自动保存设计项后，整个设计工作区切到骨架屏重载，操作被打断。
**根因**：`DesignItemSheet` 保存成功后 `emit('saved')`，父页面 `DesignerDesignWorkspaceView` 绑定的 `loadScheme()` 会重新拉取方案且把 `loading=true`（整页骨架），并丢弃列表上下文。

**修复**：
- 父页面 `@saved` 改为 `onItemsSaved(updated)`：只把返回的 `spaces/items/统计` **就地合并**进当前 `scheme`，不重新拉取、不切骨架屏，文件签名等字段保留。
- `DesignItemSheet` 保存成功后用 `reconcileItems()` **按 itemId 就地核对**（保留已有行 key 与编辑态，新行补 itemId），不再整体重建表格，避免跳动/失焦。

**实测**（真实设计师账号）：新增分项后 `design/scheme/info` = **0** 次（不再重载），仅 `design/items/save` = 1 次（整表原子保存）；删除后同样 0 次；控制台 0 error；测试行已删除、数据还原。

## 二·补4 · 设计分项弹窗支持拼音首字母查询（用户反馈修复）

**问题**：报价分项选择弹窗只能按中文名称匹配，输入拼音首字母查不到。

**根因**：后端 `catalog/item/page` 的 `keyword` 已支持拼音首字母（实体 `CatalogItem.nameInitials` 上有 `@Keyword`，检索命中 `nameInitials`，注释示例 `QGLG → 轻钢龙骨石膏板吊平顶`）；但 V3 弹窗是**一次性拉全部目录后前端 `includes` 过滤**，从不把关键词发给后端，所以拼音走不通。另外预加载分页判断写错（请求 200 被后端压到 100，`length < 200` 永远成立），导致目录被截断在每类 100 条。

**修复**：
- 弹窗输入关键词后**改为调用后端检索**（防抖 250ms；按所选类型或全部 6 类并发 `catalog/item/page`），后端即按 `name/code/category/brand/series/spec/nameInitials` 命中；
- 分类切换时重新检索；清空关键词回到本地已加载目录；
- 修正预加载分页：按后端 100 上限判断下一页，目录不再截断。

**实测**（真实设计师账号）：搜索 `gcglf` → 命中「工程管理费」；搜索 `qglg` → 命中「木工--轻钢龙骨…」系列 20 条；控制台 0 error；未新增/修改任何数据。
