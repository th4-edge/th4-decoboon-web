## 一、实现

`src/views/finance/FinanceWorkbenchView.vue` 新增「资金闭环」区块（位于 KPI 之后）：

```
客户侧          应收 ¥806,921.79 → 待收（未收余额）¥732,550.36 → 已收 ¥74,371.43     回款率 9.2%
供应商/员工侧    应付 ¥88,622.66  → 待付（未付余额）¥69,860.00  → 已付 ¥18,762.66     其中工资 ¥0.00
```

**与 App 的差异（有意为之，已在页面上声明口径）**：App 是「应收→已收→应付→已付」**单链四节点**；Web 改为**两行**。原因：单链会被读成「已收 → 应付」的流转关系，而这两者之间**没有资金流转**（收客户的钱不等于付供应商的钱）。两行分别表达「客户侧」与「供应商/员工侧」，语义正确。

**口径纪律**：四个数（应收/已收/应付/已付）与两个缺口（待收/待付）**全部取服务端同名字段**，**前端不做减法**；回款率取服务端 `collectionRate`。
