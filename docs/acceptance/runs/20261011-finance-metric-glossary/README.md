## 四、对 `MET-005` 的结论（重要）

`MET-005` 记录「Web 与 App 同名『本月回款』公式不同」。本轮的字典给出了**产品内可查的裁决依据**：

- 字典定义 **本月回款 = 收款登记记录（Receipt）**，**资金收入 = 资金台账（Ledger）**，两者是不同概念，各有独立名称；
- **Web 侧与字典一致**（财务工作台 KPI 的「本月回款」取 `monthReceiptAmount`）；
- 因此差异位于 **App 侧**：App 财务工作台把「本月回款」显示为 `monthIncome`（台账口径）—— 与字典命名不符。

**这属 App 侧标签/取值对齐问题，不是 Web 缺陷**；建议由业务/App 侧按字典修正（或明确 App 该处应显示「资金收入」）。本轮 Web 未改口径。
