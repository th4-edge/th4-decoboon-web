## 本轮完成

1. 交接队列：只展示本人创建且客户已接受 / 已转项目的报价。
2. 合同阶段轨道：报价已确认 → 合同已生成 → 合同已签署 → 合同已生效 → 项目已立项。
3. 报价事实：报价编号、金额、状态、创建时间。
4. 合同事实：合同编号、状态、当前金额、签署时间、生效时间。
5. 项目交接：合同生效并立项后展示项目入口；未立项时明确说明不得绕过合同创建项目。
6. 交接摘要：按报价、合同、项目、最近沟通生成可复制摘要。
7. 客户沟通：只读展示服务端跟进时间线。
8. 权限边界：设计师不创建、不签署、不生效合同；只做资料准备、跟进和交接。
