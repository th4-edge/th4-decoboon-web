# 多门店 Web UI 截图视觉批判（2026-10-17）

```text
页面: 门店经营概览 / 本店业务承接
角色: 滨湖店长、高新店长
视口: 1440×900 / 1280×800 / 1024×768
方式: Playwright Chromium 真实渲染 + 截图 + DOM/Computed Style 量测
结论: P0 对比度问题已修复；P1 响应式层级仍有 2 项建议；未做人工主观审美签字
```

## 1. D1 设计意图

### 门店经营概览

- 页面类型：经营决策页。
- 使用人：店长，打开后要知道“本店今天该处理什么、经营结果如何”。
- 首答：本店待处理事项 + 本店经营金额 + 本店经营利润。
- 唯一主行动：保存本店目标；“刷新”为次级默认按钮。
- 信息优先级：待处理事项 > 经营金额/利润 > 目标 > 设计师/项目/客户明细。
- 与 App 差异：Web 承载宽屏表格、目标维护和门店对比入口；App 承载现场快捷动作。

### 本店业务承接

- 页面类型：行动队列/专业列表页。
- 使用人：店长，打开后要知道“本店哪些在跑项目可以代确认”。
- 首答：本店待处理数量 + 可承接项目 + 阻塞项。
- 唯一主行动：代确认并承接。
- 信息优先级：本店范围与待处理数量 > 可承接项目 > 阻塞项 > 已完成项目。

## 2. 第一轮批判：命中项

### P0 对比度

| 位置 | 修复前 | 问题 |
| --- | --- | --- |
| 经营利润口径说明 | `$text-tertiary` #b8b8b0 / 12px，对白底 2.00:1 | 低于 WCAG AA 4.5:1 |
| 承接项目副标题 | `$text-tertiary` #b8b8b0 / 12px，对白底 2.00:1 | 低于 WCAG AA |
| KPI 辅助说明 `.finance-kpi small` | `$text-tertiary` #b8b8b0 / 12px，对白底 2.00:1 | 全局财务 KPI 均受影响 |
| “已具备承接条件” | `$success-500` #22a06b / 13px，对白底 3.33:1 | 低于正文 AA，且仅靠颜色表达正向状态 |

### P1 响应式层级

| 位置 | 现象 | 影响 |
| --- | --- | --- |
| 1024 门店经营概览 | 经营利润面板起始 y=1223，首屏 768 看不到 | 店长首屏看不到最重要的经营结果之一 |
| 1024 承接表格 | 表格内容宽 1210px，可视 958px，横向滚动 | 操作列已固定，可用，但“待补齐”列需横向滚动才能看全 |

### 通过项

- 1440/1280/1024 均无页面级横向溢出。
- 新增目标/利润面板无小于 12px 的文字。
- 目标与利润卡片在 1440 等宽、等高；1024 单列堆叠。
- 经营概览仅“保存本店目标”为实心主按钮，“刷新”为默认按钮。
- 承接页表格行高 63px，操作列固定。
- 键盘焦点可见：按钮 focus 时 `2px solid` 轮廓。
- 两页控制台 0 error。

## 4. 量规评分

| 维度 | 分数 | 证据 |
| --- | --- | --- |
| C1 视觉一致性 | 4/4 | 仅使用 tokens；卡片圆角 12px、阴影一致 |
| C2 信息层级 | 3/4 | 1440 首屏可见利润；1024 利润低于首屏 |
| C3 对齐与留白 | 4/4 | 1440 双卡等宽 562px、gap 16px；1024 单列对齐 |
| C4 状态完整性 | 3/4 | 有加载/失败/空态；承接页停止、阻塞态可读 |
| C5 交互清晰度 | 4/4 | 唯一主行动明确；按钮与操作列可见 |
| C6 数据可读性 | 4/4 | 金额等宽数字、右对齐；表格行高 63px |
| C7 可访问性 | 4/4 | 对比度 ≥4.5、焦点可见、无 `outline:none` |
| C8 响应式 | 3/4 | 无横向溢出；1024 利润低于首屏、承接表横向滚动 |

平均：**3.625 / 4**，达到主链页面 ≥3.5 的门槛；C2/C8 仍有 P1 改进项。

## 5. 剩余建议

1. **把本店经营利润摘要提升到顶部金额带**：1024 首屏即可看到利润或“成本未完整”，详细拆分保留在下方。
2. **1024 承接表格列取舍**：优先保留客户/项目、未收、未付、状态、操作；成本与部分说明可收进行展开。
3. **全局 KPI 辅助说明改为 `$text-secondary` 后**，需对财务工作台、薪酬、材料等使用 `.finance-kpi` 的页面做一次视觉回归。
4. 本轮未做人工审美签字和独立验收；截图与量测仅证明结构、对比度、响应式和状态可用。
