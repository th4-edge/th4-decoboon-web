# 装得清 Web V3 渲染验收与沉浸审计协议

> 只适用于本地或专用测试环境。类型检查、构建成功、接口 200 均不构成页面可用证据。

## 1. 运行门禁

1. 用户在当前任务中明确授权范围与时间窗口。
2. 后端配置、进程参数、数据库主机可证明指向本地或专用测试库；发现生产指向立即停止。
3. 写操作前生成数据库级备份并记录路径、大小、SHA-256 与恢复方式。
4. 冻结：企业、员工、角色、凭证来源、授权动作、禁止动作、场景矩阵、分辨率矩阵、运行目录、责任人。
5. 确认 Web、后端、数据库指向同一环境，Web 构建产物来自当前源码。

## 2. 身份与切换

- 每名员工使用独立登录凭证；禁止改写员工角色、企业、门店、姓名来冒充岗位。
- 每次切换必须：退出旧会话 → 清理站点数据 → 重新登录 → 打开受保护页面 → 核验员工/企业/门店/角色/数据范围。
- 禁止复用上一身份的 token、Cookie、缓存响应或未刷新标签页。

## 3. 必测矩阵

| 维度 | 最低要求 |
| --- | --- |
| 分辨率 | 1440x900 / 1280x800 / 1024x768，每档整屏截图 |
| 状态 | 正常 / 加载 / 失败 / 真实为空 / 无权限 / 会话过期 / 长内容 |
| 权限负向 | 跨企业、跨门店/团队、同角色他人、直开 URL、改参数、刷新 |
| 键盘 | ≥1 条关键路径纯键盘完成；弹层 Esc 关闭并归还焦点 |
| 对账 | 业务键的页面 / 接口 / 数据库三方一致 |
| 跨端 | 同一事实在 App 与 Web 口径一致；差异建 `DEF-*` |

## 4. 证据

```text
docs/acceptance/runs/<run-id>/
  00-执行计划与授权.md  01-运行清单.md  02-体验日志.md
  03-角色独立评价.md    04-场景与状态矩阵.md  05-跨角色对账.md
  06-问题台账.md        07-最终结论.md
  raw/{screenshots,console,network,api,sql,notes}/
```

截图命名：`<step-id>__<role>__<viewport>__<before|after>__<desc>.png`。
禁止记录密码、哈希、完整 token、Cookie、Authorization 头。

## 5. 结论分级

`PASS` / `FAIL` / `BLOCKED` / `NOT_TESTED` 分列；未跑通的角色或阶段不得包装成通过。
问题编号 `XA-YYYYMMDD-NNN`，类别 `UX/BIZ/DATA/BUG/SEC/GAP/DOC`，分级 `P0–P3`。

## 6. 完成条件

1. 授权、备份、角色凭证、回滚证据齐全。
2. 场景矩阵达到约定轮次与状态数，关键交接均有浏览器 UI 证据。
3. 每次角色切换完成身份、闭环、金额/状态、正向与负向权限核验。
4. 关键页面完成三档分辨率核验，≥1 条关键路径完成键盘操作。
5. P0/P1 缺陷均有最小复现与证据；未修复项不得写成已通过。
