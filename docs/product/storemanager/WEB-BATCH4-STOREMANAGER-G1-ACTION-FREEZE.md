## 1. 角色定位

店长是**本店范围的负责人能力子集**，不是 BOSS 全企业能力的缩小副本：

- 数据范围固定为 `Store`（本门店），跨店一律阻断。
- 有本店风险/待办处置、客户负责人转交、设计师指派和项目基础维护能力。
- 财务为**只读**：可见本店成本、利润、毛利率和员工工资构成，但不得执行收付款、台账和凭证写动作。
- 成本、利润、毛利率可见（BR-003 / BR-029），但**不得扩大口径**；无权限时该区块不生成，而不是置 0。
- 敏感字段（身份证、银行卡完整值、个税明细）对店长脱敏（BR-007 / BR-015）。
- 不得获得 BOSS 的企业全量、跨店、代业主确认或财务写能力（BR-028）。

## 2. 已冻结写动作

| 动作 | 角色 | Provider | 范围约束 |
| --- | --- | --- | --- |
| 转交客户负责人 | StoreManager / Boss | `customer/owner-change` | 店长只能转交本门店在职人员，且只能转给业务员/设计师/团队负责人/店长/企业负责人 |
| 指定设计师 | StoreManager / Boss / TeamLeader | `customer/designer-handoff` | 店长只能指派本门店设计师或 BOSS 本人；客户必须已跟进且有房屋 |
| 更新项目基础信息 | StoreManager / Boss / Pm | `project/project/update` | 店长仅限本门店项目 |
| 维护凭证模板 | StoreManager / Boss / Finance | `voucherTemplate.manage` | 企业范围内复制/编辑/发布自有模板；平台基础模板只读 |

共同边界：

- 数据范围由服务端按登录员工裁决，前端不得传 `companyId/storeId/empId` 作为授权依据。
- 写动作必须幂等、留审计、按 `reloadScopes` 回读。
- 高风险动作（转交、指派）进入安全门并展示变更前后事实。

## 3. 只读能力（生成区块，不生成写入口）

| 面 | 可见 | 不可见/脱敏 |
| --- | --- | --- |
| 本店客户/房屋/设计/报价/合同/项目 | 本店只读 | 跨店对象不返回 |
| 应收/应付/收付款/台账/凭证 | 本店只读（`FinanceAccessContext.requireReader` 含 StoreManager） | 无写入口；超范围项目返回“不存在或无权访问” |
| 成本/标准成本/供应商报价历史/项目毛利 | 本店可见（BR-003） | 不得改口径或伪造 |
| 员工工资 | 本店员工应发/扣款/实发构成（BR-015） | 银行卡、身份证、个税明细脱敏 |
| 工人档案 | 本店脱敏档案（BR-007） | 身份证/银行卡完整值不可见 |

## 4. 明确拒绝（负向矩阵）

- 财务写动作：`finance/receivable/save`、`finance/receipt/save`、`finance/payable/save`、`finance/payment/save`、`finance/ledger/save|update|delete|correct` 全部拒绝（`requireEditor` 仅 Boss/Finance；作废更正仅 Boss）。
- 凭证生成 `document/voucher/build`：店长无权限（仅 Boss/Finance）。
- 阶段验收提交/确认：店长拒绝（T12-BIZ-20261007-006）。
- 跨店客户转交 / 跨店设计师指派：拒绝。
- 代业主确认/驳回、代财务制单、代 BOSS 做企业级决策：拒绝。
- 跨企业、跨门店、非本店项目、离职人员：拒绝。

## 5. 页面批次范围

本批先审计/建设店长可见面：

- 店长工作台（今日主线，`today.mainline`）
- 本店风险队列（`boss.risk`）
- 客户跟进（`customer.followup`，本店只读 + 转交/指派入口）
- 报价（`designer.quote`，本店只读）
- 项目（`pm.project` 只读入径）
- 财务只读：应收/应付/收款/付款/台账/凭证（复用 Finance 页面，店长只读态）
- 凭证模板维护（`voucherTemplate.manage`）

不做：店长专属新 API、店长财务写入口、店长跨店视图。

## 6. 验收门槛

- 正向：本店风险处置、转交本店负责人、指派本店设计师、模板维护。
- 反向：跨店转交/指派拒绝；财务写动作拒绝；验收提交拒绝；敏感字段脱敏。
- 越权：跨企业、非本店项目、离职人员。
- 幂等：转交、指派、项目更新重复提交。
- 金额：成本完整才显示利润；不完整显示“成本未完整”，不得置 0。
- 页面：真实店长账号、三档分辨率、只读态无写入口。
