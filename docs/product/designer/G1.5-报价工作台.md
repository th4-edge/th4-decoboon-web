## 一、设计意图七问

### 问 1 · 这是什么页面类型？

**C 对象工作空间**（报价单），内嵌 **F 单据/表格能力**。

不是列表页——报价单本身是主体；列表（报价池）是它的**选择器**，不是主角。

> 反模式检查：这是"从业务场景推出来的对象工作空间"，不是"从 `Quote` 实体推出来的 CRUD 页"。

### 问 2 · 谁在什么状态下打开它？

**设计师**，在以下状态：

| 场景 | 状态 | 打开后要做什么 |
| --- | --- | --- |
| 常规组价 | 报价 `Draft` | 逐项调工程量、单价，提交客户 |
| 客户驳回后 | 报价 `Rejected` | 按反馈改版重报，或回设计方案调整 |
| 客户接受后 | 报价 `Accepted` | 只读确认，转合同交接 |
| 集中分配 | 多份 `Draft` | 批量套模板、快速逐份处理 |

### 问 3 · 他打开后第一个要得到的答案是什么？

> **"这单报价现在是什么状态、金额多少、我要改哪一项、改完客户会不会接受。"**

一句话：**当前报价是否可提交、差在哪里。**

### 问 4 · 唯一主行动是什么？

按状态唯一：

| 报价状态 | 唯一主行动 |
| --- | --- |
| `Draft` | **保存草稿**（未保存时）；保存后变为 **提交客户确认** |
| `Rejected` | **改版重报**（或走「回设计方案调整」的次路径） |
| `Submitted` | 只读，等待客户决策 |
| `Accepted` | **转合同交接** |

### 问 5 · 信息优先级（≤3 层）

```text
第一层 结论：报价状态 · 服务端正式总额 · 版本号 · 是否可提交
第二层 行动：唯一主行动 + 提交前检查（成本完整性/折扣/税金/未确认差异）
第三层 证据：报价明细（区域分组）· 版本差异 · 图纸参考 · 客户上下文
```

### 问 6 · 与 App 同一对象差在哪？（Web 存在的理由）

| 维度 | App | Web |
| --- | --- | --- |
| 编辑方式 | 逐条表单 | **12 列表格 + 行内编辑 + 工程量公式** |
| 批量 | 一次一条 | **批量套模板、表头批量改价、跨行编辑** |
| 对照 | 看不到 | **三栏并行：版本/区域 ← 报价表 → 客户决策** |
| 版本 | 单版本 | **版本切换 + 版本差异对比（五类差异筛选）** |
| 数据进出 | 手工录入 | **整表导入/导出 Excel** |
| 键盘 | 触屏点按 | **Enter 提交、Ctrl/Cmd+S 保存、双击行内编辑、方向键跨格** |
| 全屏 | — | **工作区全屏 + 屏幕全屏（投屏演示用）** |

> 如果这些差异不存在，这个页面就该留在 App。**它们就是这个页面存在的理由。**


> **降级原则**：先牺牲并列信息（抽屉化），**不牺牲表格编辑能力**。

## 三、七类状态设计

### 3.1 页面级（7 类）

| # | 状态 | 设计 |
| --- | --- | --- |
| 1 | **正常** | 三栏渲染；报表状态决定可编辑性 |
| 2 | **加载中** | **骨架屏**：报价头骨架 + 左栏版本骨架 + 表格 6 行骨架；**禁止遮罩转圈**（避免加载完布局跳动） |
| 3 | **真实为空** | 分三种：① 报价无分项 → 「还没有报价分项」+「新增分项 / 从项目库选择」；② 无历史版本 → 「暂无上一版本」；③ 无区域 → 「未分组」 |
| 4 | **请求失败** | 顶部错误条 + **「重新加载」**；表格区表达 **「暂不可确认」**，**严禁显示 0 或空报价**（V2 已有 `loadError` + retry） |
| 5 | **无权限** | 非本人负责报价 → 不泄露客户名与金额，给返回入口 |
| 6 | **会话过期** | 清会话 → 登录 → 回到原 `quoteId` |
| 7 | **长内容 / 极端值** | 超长项目名与品牌规格（截断 + title）；超长金额（右对齐、不换行）；0.001 精度工程量；999 行（虚拟滚动）；超长客户名 |

### 3.2 动作级（4 类）

| # | 状态 | 设计 |
| --- | --- | --- |
| 8 | **提交中** | 主按钮 loading；**禁止重复提交**；工具栏禁用 |
| 9 | **提交成功** | 明确反馈 + **重新拉取服务端报价**（不本地猜状态） |
| 10 | **提交失败** | 保留全部编辑内容（**不清空草稿**）+ 具体原因 + 可重试 |
| 11 | **业务状态冲突** | 报价已被他人推进 / 已是 `Submitted` → 提示「报价状态已变化，已为你重新读取」并转只读 |

### 3.3 关键状态规则（来自 V2）

- **未保存提示**：`dirty` 时工具栏显示「有未保存修改 · 正式金额未变」；离开页面拦截。
- **编辑预览 vs 正式金额**：右栏同时显示「服务端已保存 / 本次编辑预览 / 与已保存差额」，并明确 **"预览仅供即时核对，正式金额以服务端重算为准"**。
- **提交前检查**：成本完整性 / 折扣 / 税金 / 未确认差异。
- **驳回双路径**：报价内容调整（改版重报，生成 V{n+1} 草稿）｜设计方案调整（回设计方案改，再重新生成快照）。**驳回版本保持只读，禁止在原历史版本上直接改数。**

## 四、组件复用清单

### 4.1 直接复用（Element Plus）

| 组件 | 用途 |
| --- | --- |
| `el-button` / `el-input` / `el-input-number` | 基础控件（**行内输入用 `:controls="false"`**，保持表格紧凑） |
| `el-alert` | 错误条、警告、提示 |
| `el-tooltip` | 截断内容的完整提示 |
| `el-dropdown` | 1280/1024 的「更多」操作 |

### 4.2 需新建（V3 业务组件，登记后复用）

| 组件 | 职责 | 新建理由 |
| --- | --- | --- |
| `QuoteHeader` | 报价头（身份 + 状态 + 正式总额 + 主行动） | 三段栅格与状态联动是本页专有；第二处使用前登记 |
| `QuoteVersionRail` | 版本切换 + 区域分组（含金额、项数、收起） | 折叠态与选中态逻辑复杂 |
| `QuoteSheetToolbar` | 新增/删除/导入/导出/保存 + 未保存提示 | 与 `dirty` 状态强绑定 |
| `QuoteFormulaBar` | 区域·行号 + 公式输入 + 跳转 | 与选中单元格强绑定 |
| `QuoteSheetGrid` | 12 列可编辑表格 + 冻结列 + 虚拟滚动 | **原生 `<table>` 更贴合 Excel 语义**；`el-table` 在行内编辑+公式栏联动下成本更高 |
| `QuoteDecisionPanel` | 报价汇总（已保存/预览/差额/小计/优惠）+ 决策 Tabs | 预览口径必须唯一实现 |
| `StatusTag` | 状态标签（14 tone） | 全局复用（禁止各页自造标签） |
| `MoneyText` | 金额展示 | 统一右对齐、精度与「暂不可确认」 |
| `EmptyState` | 真实为空 | 必须给下一步 |
| `SkeletonBlock` | 骨架屏 | 首屏与表格加载 |
| `CostIncompleteValue` | 成本未完整 | 全局口径（设计师侧一般不出现成本，但复用同一组件） |

### 4.3 禁止

- 禁止为本页自造第二套状态标签、空态、错误态、卡片。
- 禁止用 `el-table` + 弹窗表格**替代**电子表格式行内编辑（会丢掉公式栏与跨格键盘流）。

## 五、Web 提升点（G1.5 必答，全部落位）

| 提升点 | 落位 |
| --- | --- |

| 经营 | 右栏「报价汇总」即时差额（正式金额仍以服务端为准） |
