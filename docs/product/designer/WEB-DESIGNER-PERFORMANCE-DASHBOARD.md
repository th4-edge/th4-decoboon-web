# Web 设计师 · 我的业绩页面实施基线

> 状态：实施基线（2026-10-10）  
> 批次：`DESIGNER-PERFORMANCE-REFACTOR-20261010`  
> 页面：`/designer/performance`  
> 角色：Designer  
> 事实来源：`BR-005`、`MET-001`、`MET-004`、`DEC-034` / `BR-030`、`DEC-018`、Web 业务指标注册、现有 `statistic/workbench/designer/report` Provider  
> 边界：不新增业务对象、状态、动作、权限、金额和成本口径，不新增 API。

## 1. 页面定位

我的业绩不是把客户、房屋、报价和项目全量拉到前端重新计算，而是一个只读经营结果投影：

1. 先看本月结果：在途客户、本月报价金额、本月签约金额；
2. 再看个人排名与激励：本月签约额名次、团队均值、距第一名/团队均值差额、前 5 名摘要；
3. 再看方案报价主链：量房 → 设计 → 报价 → 合同；
4. 再看近 30 天量房完成、报价提交、客户接受、合同生效趋势；
5. 最后看当前工作分布和当前最值得推进的动作；
6. 对无基期、小样本、部分可用、缺失值保持明确表达。

## 2. 真实场景

### 场景 A：月中复盘，判断本月签约节奏

- 使用人：设计师本人。
- 触发事件：月中查看个人经营结果，准备调整报价和签约推进节奏。
- 当前动作：打开「我的业绩」，看本月报价金额、本月签约金额及较上月变化。
- 系统下一步：通过方案报价主链显示当前待处理阶段，并提供进入待我处理的入口。
- 异常处理：本月无报价/签约时显示真实 0；无基期时显示“暂无基期”，不制造无穷增长。

### 场景 B：周度复盘，定位工作积压

- 使用人：设计师本人。
- 触发事件：每周检查待量房、待设计、待谈单、待客户确认和合同交接。
- 当前动作：查看近 30 天趋势和当前工作分布。
- 系统下一步：从主链或工作分布进入对应工作台处理，不在业绩页写业务状态。
- 异常处理：聚合接口失败显示“暂不可确认”与重试；部分数据可用显示明确告警。

## 3. 数据边界

| 用途 | Provider | 说明 |
| --- | --- | --- |
| 本月概览、排名、主链、趋势、工作分布、告警 | `statistic/workbench/designer/report` | 唯一事实源，服务端聚合 |
| 客户、报价、项目明细 | 不在本页拉取 | 通过主链/工作分布进入已有工作台 |
| 成本、毛利、利润 | 不展示 | 设计师无成本利润区块 |

- 页面不查询 `customer/customer/page`、`property`、`quote`、`project/project/page` 进行本地统计。
- 所有正式数值直接消费服务端 summary、pipeline、charts、cards 和 warnings。
- 变化率只消费服务端 `changeRate/comparisonState/comparisonLabel`；无基期保持未计算。
- 排名只消费服务端 `performanceRanking`：本月签约额、本人名次、团队均值、差额和前 5 名摘要；样本少于 3 人显示“仅供参考”。
- 当前工作分布和主链只使用服务端主数量；不把相对条宽解释为转化率。

## 4. 页面结构

```text
Header
→ 数据截止时间 / 数据范围 / 刷新

本月经营结果
→ 在途客户
→ 本月报价金额 + 服务端环比
→ 本月签约金额 + 服务端环比

排名与激励
→ 本人名次 / 团队均值 / 差额 / 前 5 名 / 当前优先动作

方案报价主链
→ 量房 / 设计 / 报价 / 合同
→ 服务端 count、state、description、route

近 30 天业务趋势
→ 量房完成 / 报价提交 / 客户接受 / 合同生效

当前工作分布
→ 待我量房 / 待我设计 / 待我谈单 / 待客户确认 / 合同交接
→ 项目推进 / 待我选材 / 增减项 / 验收整改

指标口径
→ 数据来源、缺失值、无基期、只读边界
```

## 5. 状态与异常

| 状态 | 页面表达 |
| --- | --- |
| 加载中 | 骨架屏，不显示旧值 |
| 真实为空 | 服务端返回 0 时按主数量展示；无客户时主链为空态 |
| 无基期 | 明确显示“暂无基期” |
| 部分数据可用 | 显示服务端 warnings，保留成功区块 |
| 读取失败 | 全页错误 + 重新加载 |
| 规则未命中 | 不展示未裁决指标，不显示伪接受率 |
| 无权限 | 路由和服务端双重限制；不泄露其他设计师数据 |

## 6. 响应式与验收

- `>1280px`：Hero 右侧三张本月指标同屏，趋势与工作分布双栏。
- `1025–1280px`：主内容单栏，趋势在工作分布上方。
- `<=1024px`：单列，摘要卡纵向排列，无横向溢出。
- 1440/1280/1024 真实浏览器无横向溢出，控制台 0 error。
- 正向：本月金额、环比、主链数量、趋势和工作分布与 Provider 一致。
- 反向：未知/失败状态不显示 0 伪值；页面无成本、毛利、利润区块；不展示未经裁决的正式接受率。
- 键盘：刷新、主链 CTA、工作项入口可聚焦。
