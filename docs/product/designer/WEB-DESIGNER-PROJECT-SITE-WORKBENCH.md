# Web 设计师 · 项目工地工作台实施基线

> 状态：实施基线（2026-10-10）  
> 批次：`DESIGNER-PROJECTS-REFACTOR-20261010`  
> 页面：`/designer/projects`  
> 角色：Designer  
> 事实来源：`DEC-034` / `BR-030`、`DEC-033` / `BR-029`、`T12-BIZ-20261009-005`、`SCN-003`、`G1-迭代包`、现有 App 项目/阶段/任务/现场/验收 Provider  
> 边界：不新增业务对象、状态、动作、权限、金额/成本/利润口径，不新增 API。

## 1. 页面定位

项目工地不是“项目列表 + 全量字段详情”，而是设计师进入本人参与项目后的对象协同工作面：

1. 先从本人项目队列定位当前项目；
2. 在一个项目 Hero 中看清当前阶段、进度、风险和责任接棒；
3. 只看当前阶段真正需要协同的任务与现场事实；现场动态与验收事实采用上下排列的 App 卡片流，支持图片九宫格预览和视频首帧/播放，不左右并排；
4. 通过右栏进入设计师拥有合法能力的项目工作区；右栏直接提供“新增增减项”和“查看历史增减项”；
5. 项目成本、毛利和利润对设计师不生成任何区块。

## 2. 真实场景

### 场景 A：施工推进中，设计师核对本阶段落地

- 使用人：设计师，负责 3 个在施项目。
- 触发事件：项目经理刚更新现场进度，设计师需要确认当前施工阶段和任务是否与设计交底一致。
- 当前动作：进入项目工地，从队列选择项目，查看当前阶段、阶段任务、最近现场动态。
- 系统下一步：显示服务端项目状态视图的当前推进点、主责角色；设计师通过主行动进入主材选材，或查看增减项/验收。
- 异常处理：阶段、任务、现场任一读取失败时，保留其他已成功区块，并显示“部分数据暂不可确认”。

### 场景 B：项目停工或交付风险，设计师不能越权推进 PM 动作

- 使用人：设计师，同时参与客户设计和交付协同。
- 触发事件：项目状态为停工/待验收，现场存在阻断原因。
- 当前动作：查看项目风险、下一责任人和可进入的交付工作面。
- 系统下一步：唯一主行动仍是“打开主材选材”；PM 的复工、节点推进和验收动作只展示责任与去向，不生成可点击的设计师主按钮。
- 异常处理：服务端未返回动作策略时显示“待业务确认”，不得由前端按状态猜测下一步。

## 3. 三栏职责

| 栏位 | 回答的问题 | 本页实现 |
| --- | --- | --- |
| 左栏 | 现在有哪些本人项目可处理 | 服务端分页队列、项目身份、客户/房屋锚点、状态、当前阶段、风险/接棒原因、计划日期 |
| 中栏 | 当前项目真实事实是什么 | 唯一项目 Hero、服务端 `businessStateView` 阶段关注、阶段轨道、当前阶段任务、现场动态、验收事实 |
| 右栏 | 为什么关注、设计师能做什么、做完去哪 | 服务端项目推进点、唯一主行动“打开主材选材”、其他合法项目工作区、下一接棒、下一项 |

## 4. 对象与锚点

- 主对象：项目。
- 子锚点：当前阶段；切换阶段必须写回 `activeStageId`，刷新可恢复。
- 项目锚点：`activeProjectId`；首次没有指定锚点时不默认选中第一条，显示“请选择一个项目”。
- 筛选与搜索：状态和关键词按服务端分页查询；筛选变化后当前对象不在结果中时，按规范联动到新队列首位；结果为空则清空中栏与右栏。
- 页面不读取其他设计师或 PM 项目：数据范围仍由服务端 `project/project/page` 强制限制。

## 5. 状态与动作

- 项目、阶段、任务、验收状态统一使用 `BusinessStateTag`，页面不维护英文枚举中文表。
- 项目“下一步”只消费 `businessStateView.nextAction`；设计师主行动不是项目状态推进动作，而是合法工作区“打开主材选材”。
- PM 动作只能展示“责任人/完成后状态/阻断原因”，不得伪装成设计师可执行按钮。
- 不发生写动作，因此无幂等、二次确认和审计新增要求；进入下游工作区后由该工作区负责门禁与回读。

## 6. 数据与权限

| 用途 | Provider | 角色边界 |
| --- | --- | --- |
| 项目分页 | `project/project/page` | 服务端按 Designer 参与关系过滤；只读附带应收/已收回款进度 |
| 项目详情 | `project/project/info` | 仅当前项目可读 |
| 阶段 | `project/stage/page` | 随项目数据范围 |
| 任务 | `project/task/page` | 设计师只读 |
| 现场动态 | `project/report/page` | 设计师只读 |
| 验收 | `project/acceptance/page` | 设计师查看；提交/确认由验收工作区按服务端权限裁决 |
| 主材选材 | `/designer/projects/:projectId/materials` | 设计师可维护，进入后由选材工作区校验门禁 |
| 新增/历史增减项 | `/designer/projects/:projectId/changes` | 右栏新增动作携带 `action=create` 自动打开发起抽屉；进入后由变更工作区校验合同、角色和客户确认门禁 |

- 不显示项目成本、毛利、利润和成本变化。
- 合同金额只读，使用 `MoneyText` 展示；无值显示“暂不可确认”。
- 回款进度只读取项目应收计划汇总中的“应收 / 已收”，不使用合同额或本地比例冒充；未生成应收计划时显示“待生成应收”。
- 现场动态读取 `Report.images`，验收事实读取 `Acceptance.evidenceUrls`；媒体通过私有文件授权后展示，图片支持九宫格预览，视频显示首帧并弹窗播放。

## 7. 页面状态

| 状态 | 页面表达 |
| --- | --- |
| 加载中 | 队列、Hero、阶段/任务面保留骨架，不闪空态 |
| 真实为空 | 说明“当前账号没有参与项目”及合同生效/立项条件 |
| 筛选后为空 | 提示清除搜索或状态筛选，不冒充无项目 |
| 列表读取失败 | 全页错误 + 重试，保留当前 URL 锚点 |
| 对象部分失败 | 成功区块保留，失败区块显示“部分数据暂不可确认” |
| 未指定项目 | 中栏/右栏显示“请选择一个项目”，不默认第一条 |
| 状态未登记 | `BusinessStateTag` 显示“待业务确认” |
| 无权限 | 显示数据范围原因和返回工作台入口，不生成项目内容 |

## 8. 响应式与验收

- `>1400px`：三栏同屏，左右栏吸顶。
- `1025–1400px`：左 + 中两栏，右栏移至中栏下方。
- `<=1024px`：单列，取消吸顶和强制内部滚动。
- 1440 / 1280 / 1024 三档均验证：无横向溢出、Hero 与状态引导首屏可见、控制台 0 error。
- 正向：选择项目 → 阶段/任务/现场/验收与真实 Provider 一致。
- 反向：跨项目 ID、其他设计师项目 URL、未知状态、无数据、部分接口失败都有明确表达。
- 键盘：搜索、筛选、项目卡、阶段卡和右栏动作均可 Tab 聚焦，焦点可见。
