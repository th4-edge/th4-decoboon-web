## 3. 公式规则

区域分项优先使用专业变量：

| 业务类型 | 公式 |
| --- | --- |
| 地面、地砖、地板、集成吊顶、墙顶面 | `=A` / `=WP` |
| 踢脚线 | `=P-DW` |
| 墙面基层、腻子、乳胶漆 | `=WP` |
| 防水 | `=A` |
| 固定数量项目 | 默认数量 1；无可靠变量时默认 0，由设计师在工作台补录 |

模版创建后，缺少长宽高的区域会生成“待补尺寸”设计项，数量为 0；补齐尺寸后才能产生有效工程量。

空间尺寸保存后会由服务端自动重算：

- `Formula` 来源的公式分项；
- 当前空间下的 `=A / =WP / =P-DW`；
- 全屋共享的 `SUM(A) / SUM(P) / SUM(WP)`；
- 分项工程量与金额。

设计师手工调整过的 `Manual` 分项不会被空间尺寸变化覆盖。

> 当前方案空间只采集长、宽、高；门洞、窗洞和防水上返暂按 0 参与计算，后续补齐空间字段后再提高精度。
