### 1.1 准入三问

1. **谁在什么状态下打开**：设计师每天上班打开 Web，或店长集中分配多套房屋后打开。
2. **第一个答案**：今天有几件事卡在我这里（待设计/需调整/待签约），哪件最急。
3. **唯一主行动**：处理最紧急事项——推进设计、调整报价、或完成合同交接。

### 1.2 真实场景（2 个）

**场景 A · 单店成长型（10–20 人）**
- 使用人：董夏鹏（设计师）
- 触发事件：周一早上登录，上周 3 个客户量房完成未录诉求、2 份报价被驳回、1 份报价确认后 5 天未签合同
- 前置条件：客户已分配给他，房屋已建立
- 当前动作：在 App 上要在「客户」「报价」「项目」三个列表反复按状态筛选
- 系统下一步：今日工作按阶段聚合成三条队列，按停留天数倒序，点卡片直接进处理
- 异常处理：聚合接口失败显示「暂不可确认」+ 重试，不显示空列表

**场景 B · 多店成长型（2–3 店，20–30 人）**
- 使用人：谢玲玲（设计师）
- 触发事件：店长集中分配了 8 套同户型房屋，只需套用同一报价项目库模板微调
- 前置条件：报价项目库已维护、套餐模板可用
- 当前动作：App 上只能一份份编辑，8 份要点 8 轮
- 系统下一步：报价列表多选 + 批量套模板 + Excel 式工作区编辑，逐份提交
- 异常处理：单份保存失败逐份提示原因，成功项不回滚，失败项可重试

## 4. 业务闭环（对齐 App 05 文档）

```text
登记/接收客户 → 持续跟进 → 选择企业套餐 → 服务端生成报价快照
→ 提交客户确认 →（客户接受）报价转项目 → 生成 7 阶段施工计划
→ 按阶段/区域/工艺排期 → 任务下发 PM → 节点留证 → 现场动态与日报
→ 提交阶段验收 → 业主确认 → 阶段完成 → 设计业绩汇总
```

### 4.1 职责边界（App 原文）

**做**：承接本人客户、沉淀跟进、基于户型/面积/套餐生成报价（金额服务端算）、推动报价提交与客户确认、
由已接受报价立项、按「阶段×区域×工艺×数量」编排施工任务、查看节点留证与验收结果、查看本人业绩。

**不做（服务端同样拦截）**：看其他设计师的私人客户/报价/项目、做 PM 的开工与节点确认、
碰企业资金结算与全局经营数据、改服务端计算的金额/成本/进度。

### 4.2 GAP-D2 结论（由 App 证据解答）

App 合同签约文档明确：**签约与生效仅 BOSS 可执行**；其他角色看到「请联系企业负责人完成合同签约」。
App/Web 动作对齐表也确认「设计师无签约权，两端一致」。

**结论**：Web 设计师侧为 **「合同交接」（只读摘要 + 催办）**，不实现签约动作。
命名必须叫「合同交接」，**不得叫「签约工作台」**。

## 7. 权限矩阵

**正向**：查看与维护本人客户、房屋、量房、方案、报价；发起转项目；编排本人项目的施工任务；
维护选材；发起增减项；提交阶段验收；查看本人业绩。

**负向（必须验证）**

| 负向用例 | 期望 |
| --- | --- |
| 查看其他设计师的客户/房屋/报价 | 列表不可见；直开 URL 与接口均拒绝 |
| 合同签约/生效 | 无入口；接口 403（`contract:write` 属 BOSS/店长） |
| 报价项目库维护 | 无入口；接口拒绝（设计师无 `catalog:write`） |
| 查看标准成本 | 不返回 `costPrice`；页面无成本字段（无 `catalog:cost`） |
| 查看项目成本/毛利/成本变化 | 整体隐藏（App 红线：PM/设计师/业务员不可见） |
| 代业主确认验收 | 无入口；接口拒绝（仅业主本人） |
| 企业财务、成员、门店、团队管理 | 无入口；接口拒绝 |
| 跨企业访问 | 拒绝，不泄露对象名称 |

## 8. 金额、成本与口径

- 报价金额由服务端 `QuoteContext` 计算，**前端不手填、不自算**；报价创建即保存套餐快照。
- 合同金额六字段只读展示；设计师**不可修改**合同与金额。
- 项目成本/毛利/成本变化对设计师**整体不可见**（不显示 0 或 `--`）。
- 选材与验收整改**不改变任何金额**（App 强约束）→ Web 这两处**不得出现金额区**。
- 增减项会改合同金额，但原报价与原合同行不可变；设计师可发起，**不可审批**。
- 成本不完整时显示「成本未完整」，禁止伪利润。

## 9. 可完成状态投影

```text
待设计项 = 客户.designer = 我 AND 无设计方案 AND 签约前
分子 = 其中已录入设计诉求的条数
分母 = 待设计总条数
异常态 = 聚合接口失败 → 「暂不可确认」，不显示 0 / 空
```

禁止：前端本地布尔、`done:true`、空数组伪装完成、把「方案完成」当「已签约」。
