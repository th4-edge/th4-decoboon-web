## 1. 目标

Web 作为桌面端批量管理和编辑入口，支持平台基础模板查看、复制、企业模板编辑、版本发布、预览、打印和历史版本查看。

## 2. 页面结构

```text
财务
  -> 凭证模板
      -> 平台基础模板
      -> 我的模板
      -> 模板详情
      -> 模板编辑
      -> 版本历史
```

## 3. 路由规划

- `/finance/voucher-templates`
- `/finance/voucher-templates/:templateId`
- `/finance/voucher-templates/:templateId/edit`
- `/finance/voucher-templates/:templateId/versions`

保留现有 `/finance/voucher-templates` 路由，替换当前单页预设编辑器。

## 4. 页面能力

### 模板库

- 页签：平台基础模板、我的模板。
- 筛选：凭证类型、业务场景、状态、编码、更新时间。
- 操作：查看、复制、编辑、发布、停用、版本历史。
- 平台模板只读，企业模板按状态控制操作。

### 模板详情

- 基本信息：编码、名称、类型、来源、版本、状态。
- 版式预览：A4/A5、横竖版、分页和签字栏。
- 字段清单：key、显示名、必填、来源、角色可见性。
- 版本信息：当前版本、发布时间、发布人、来源版本。

### 复制模板

- 选择平台基础模板或本企业模板。
- 输入新模板名称和说明。
- 创建企业草稿，不允许直接修改来源模板。
- 复制成功后进入详情或编辑页。

### 编辑模板

- 模板名称、说明。
- 纸张、方向、页边距。
- 字段显示名、顺序、分组、显隐。
- 表格列顺序、列宽。
- 字体、字号、颜色、行距。
- 签字栏、盖章位、附件、备注、联次。
- 企业附加字段。
- 实时预览：样例数据、真实数据脱敏模式。

### 发布与版本

- 发布前执行必填字段、来源绑定、金额规则、分页和 PDF 渲染校验。
- 发布后生成不可变版本。
- 历史版本只读，可查看、对比、停用。
- 删除仅针对草稿；已发布版本不能物理删除。

## 6. API 契约

| 能力 | Provider | 说明 |
| --- | --- | --- |
| 平台模板列表 | `document/baseline/list` | 只读基础模板 |
| 企业模板分页 | `document/voucher-template/page` | 支持类型、状态、关键词筛选 |
| 企业模板详情 | `document/voucher-template/info` | 含来源、版本、字段和版式 |
| 复制/新建草稿 | `document/voucher-template/save` | 传来源模板和版本 |
| 编辑/发布/停用 | `document/voucher-template/update` | 服务端校验版本冲突 |
| 删除草稿 | `document/voucher-template/delete` | 仅草稿 |
| 凭证生成 | `document/voucher/build` | 可指定企业模板版本 |

## 7. 权限与异常

- BOSS、店长、财务可编辑和发布。
- 跨企业、跨店、越权拒绝。
- 模板版本冲突提示重新读取，不覆盖。
- 网络失败显示“暂不可确认”并提供重试。
- 平台模板编辑入口不可见或禁用，服务端仍拒绝。
- 敏感字段预览按当前用户角色脱敏。

## 8. Web 验收

- 平台模板只读。
- 复制、编辑、发布、停用、删除草稿闭环。
- 必填字段不可删除。
- 历史版本只读，模板修改不回溯凭证。
- Web 与 App 读取同一模板版本。
- 预览和 PDF 渲染一致。
