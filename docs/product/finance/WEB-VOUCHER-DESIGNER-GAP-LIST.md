## 四、验收标准（补齐后）

1. 设计器内删除必填字段被拦，并给出原因与恢复路径；
2. 发布 → 修改 → 新草稿 → 再发布，历史版本与旧凭证 PDF **完全不变**；
3. 画布可显示打印分页；列宽可视化拖动；逐行高或明确统一行高结论；
4. 1440 / 1280 / 1024 三档 + 真实 PDF 导出，逐项对照「预览 = 渲染」；
5. 台账批量出证在隔离数据上跑通，同笔**重打同号**、合并仅限同一对方 + 同一项目 + 同款项类型；
6. 控制台 0 error / 0 warning。
