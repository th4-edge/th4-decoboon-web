## 修复问题

财务在 Web「员工工资 → 月度考勤」选择员工后，应出勤仍显示硬编码的 22 天，没有读取该员工工资月份对应的薪酬方案。

## 改动范围

仅 2 个 Web 文件：

- `src/components/finance/FinanceAttendanceDrawer.vue`
  - 删除应出勤默认 22；
  - 选择员工和工资月份后调用 `payroll/compensation/info`；
  - 应出勤只读显示方案天数；
  - 无方案时明确提示，不回退 22；
  - 增加竞态保护，快速切换员工/月份不会被旧请求覆盖。
- `src/domains/finance/api.ts`
  - 增加按员工和工资月份读取薪酬方案的 API 封装。

未包含：考勤编辑/删除、店长考勤权限、工资单详情、复核、作废、发放或其他未发布薪酬改动。
