构建命令：

```bash
VITE_BASE=/v3/ npm run build
```

## Nginx（`/etc/nginx/conf.d/decoboon.joytsing.com.conf`，增量）

在 `decoboon.joytsing.com` 的 443 server 内新增（生产 `location /` 不动）：

```nginx
location = /v3 { return 301 /v3/; }

location /v3/ {
    root /opt/decoboon-web-v3/current;
    try_files $uri $uri/ /v3/index.html;
    add_header Cache-Control "no-cache";
}
```

- 备份：`/etc/nginx/conf.d/decoboon.joytsing.com.conf.bak.v3-20261006-172904`
- 发布前 `nginx -t` 通过才 `systemctl reload nginx`。
