# 工作约定

## 环境

- 后端：`th4-decoboon` 仓库，`./run-dev.sh`，端口 8090。
- 本工程 dev：`npm run dev`，端口 8092（8091 被其他进程占用，已固定 strictPort）。
- 测试企业：昭青装饰；9 个角色测试账号，口令存 `~/.decoboon-local/README.txt`（不入仓库）。

## 纪律

1. 一次只推进一个角色/一条链路，先 G1 冻结再编码。
2. 页面未接入前一律显示「建设中」，禁止假数据、0 或空数组冒充完成。
3. 涉及权限、金额、跨端的改动必须带真实浏览器负向用例。
4. 引用旧知识库结论必须标注来源与状态。
5. 小改动默认 `dev` 分支直接提交；每次提交前跑 `npm run type-check` 与 `npm run build`。

## 记录

- 同一话题在 `_系统/任务/当前工作.md` 追加一行。
- 验收证据写 `docs/acceptance/runs/<run-id>/`，不覆盖历史。
