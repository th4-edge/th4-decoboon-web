# 装得清 Web V3 页面交付门禁

> 未过 G1 / G1.5 不得编码；未过 G2 / G3 不得表述为「页面已完成」。

## G1 业务与权限门禁（编码前）

- [ ] 至少 2 个真实中小装企场景（使用人、触发事件、前置条件、当前动作、系统下一步、异常处理）。
- [ ] 受影响业务对象与状态流转有事实来源（`SCN/BR/SOL/DEC` 编号）。
- [ ] 权限矩阵：哪些角色可见、可操作；正向与负向用例各 ≥1。
- [ ] 数据范围：Company / Store / Team / Self 与项目参与关系的判定来源。
- [ ] 金额/成本/利润口径：公式、来源、`costComplete=false` 时的表达。
- [ ] 可完成状态投影：`key/label/required/完成条件/异常态` 已冻结。
- [ ] 跨端一致性：与 App 同对象的差异已说明。

## G1.5 设计与构图门禁（编码前）

- [ ] 页面类型（决策页 / 行动队列 / 对象详情 / 专业列表 / 表单抽屉）已确定。
- [ ] 唯一主行动已确定。
- [ ] 信息优先级 ≤3 层。
- [ ] 构图模板与栅格已选定；1440/1280/1024 三档布局已说明。
- [ ] 七类状态设计完成（正常/加载/失败/真实为空/无权限/会话过期/长内容）。
- [ ] 复用组件清单与新增组件理由已写明。

## G2 工程门禁（提交前）

- [ ] `npm run type-check` 通过。
- [ ] `npm run build` 通过。
- [ ] 无 `any`、无静默兜底（`||`/`??`/`0` 掩盖缺失字段）。
- [ ] 无第二套设计语言（裸色值/裸字号/裸圆角）。
- [ ] 路由与请求均走集中入口，无魔法路径与直接 `axios`。

## G3 渲染门禁（交付前）

- [ ] 真实浏览器三档分辨率整屏截图（1440x900 / 1280x800 / 1024x768）。
- [ ] 至少一条关键路径纯键盘完成。
- [ ] 控制台无未处理错误；关键请求失败有可读提示。
- [ ] 正向与负向权限均已验证（含直开 URL、改参数、刷新）。
- [ ] ≥2 轮「渲染 → 批判 → 修正」记录（UI 智能体量规任一维度 ≥3，主链页平均 ≥3.5）。
- [ ] 证据写入 `docs/acceptance/runs/<run-id>/`。
